# LUMIN Commerce CEO — zero-spend research engine

Isolated Node.js research engine. No third-party dependencies, credentials, production adapters, deploy or automatic web crawling.

Run: `cd commerce-ceo && npm test && npm run research`.

The sample products are **unverified fixtures**, not actual market research. Missing evidence stays unknown. The engine can score supplied evidence and enforce default-deny policies. Next: add real read-only public data adapters with provenance, quotas and legal/robots compliance; add persistent audit logs and scheduler before any unattended operation.

**No paid API calls, ads, store publishing or purchases.**
